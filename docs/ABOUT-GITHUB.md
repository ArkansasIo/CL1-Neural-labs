## Recommended GitHub repository description

## Important scope statement

CL1 Neural Labs is a research and simulation platform. Software simulation is not equivalent to living neural tissue, and a software release is not certification of physical CL1 hardware, biological safety, stimulation safety, or institutional research approval.
