# Documentation Flags

The flags are descriptive metadata.

| Flag | Meaning |
|---|---|
| `STATUS` | implementation state: implemented, partial, planned, or reference |
| `SOURCE` | primary implementation file(s) |
| `API` | API/client contract |
| `TESTS` | relevant test files |
| `BACK` | parent documentation |
| `NEXT` | related next document |

Flags do not enable features, grant permissions, or control hardware.
