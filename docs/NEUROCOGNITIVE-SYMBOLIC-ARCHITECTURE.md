# Neurocognitive Symbolic Architecture

Each virtual neural-cluster node can route a task through brain-inspired functional software sections and produce a transparent self-explanation.

## Functional sections
- Sensory: receives encoded input.
- Working memory: holds the current task.
- Episodic memory: stores prior episodes.
- Semantic memory: stores concepts, formulas, and lesson metadata.
- Association: connects concepts and candidate procedures.
- Language: converts structured state into an explanation.
- Executive: selects and sequences a solver.
- Motor/output: emits an answer or teaching action.
- Self-monitor: reports confidence and limitations.

These are computational analogies, not implementations of human brain anatomy and not evidence of consciousness.

## Processing loop
biological or synthetic signal -> feature extraction -> symbolic representation -> memory retrieval -> reasoning -> verification -> explanation -> response -> learning record

Biological recordings can provide measured features to the first stage, but spike activity must not be silently interpreted as thoughts or subjective experience.

## Research experiments
1. classify tasks from spike features;
2. compare symbolic task accuracy with neural activity;
3. test associative memory retrieval;
4. learn maze policies;
5. predict Pong actions;
6. progress through the mathematics curriculum;
7. ablate individual computational sections.

## Self-explanation contract
Every reasoning trace records node ID, input, sections traversed, observations, reasoning steps, answer, confidence, and capability boundary.
