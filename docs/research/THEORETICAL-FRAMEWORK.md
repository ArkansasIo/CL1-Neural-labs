# Neural Network Theoretical Framework

**Project:** CL1 Neural Labs  
**Status:** Research model specification — not a validated biological model  
**Applies to:** Software simulator, replay analysis, and offline analysis of recordings

## 1. Scope and epistemic boundaries

This document defines candidate mathematical models for describing neural-like activity and recorded multichannel signals. It does not claim that a 64-channel simulator contains 64 neurons, that its graph is the culture's anatomical wiring, or that synthetic outputs reproduce living-cell behavior.

Keep these source modes separate in every dataset and result:

- `synthetic`: generated by this repository's simulator;
- `replay`: derived from a recording replayed by software;
- `imported_biological`: externally recorded biological data;
- `physical_cl1_read_only`: acquired from an authorized physical device without issuing stimulation;
- `physical_cl1_stimulation`: a separately authorized experimental mode, disabled by default and outside this document's implementation scope.

Never silently substitute synthetic data when hardware or a recording is unavailable.

## 2. Network representation

Represent a model network as a directed weighted graph:

\[
G=(V,E,W),\qquad W=[w_{ij}]\in\mathbb{R}^{N\times N}
\]

- (V) is a set of model nodes, (N=|V|).
- (E) is the set of permitted directed edges.
- (w_{ij}) is the modeled influence from node (j) to node (i).
- (w_{ii}=0) unless a model explicitly supports self-coupling.

**Important distinction:** in this repository, an MEA channel is an observation/interface location. It is not necessarily a single neuron. A channel-level matrix estimates relationships between channels and must be named *channel-level functional/algorithmic connectivity*, not anatomical synaptic connectivity.

A spatial prior for an illustrative model may be:

\[
p_{ij}=p_0\exp(-d_{ij}/\ell)+p_{\mathrm{long}}
\]

where (d_{ij}) is the distance between modeled locations, (ell>0) is a length scale, and (p_0,p_{\mathrm{long}}\) are model parameters. This is a simulation assumption, not a universal law of cortical wiring.

## 3. Discrete-time activity model

For a general rate-based model, let (x_i(t)\in[0,1]) denote normalized activity, not a measured membrane voltage:

\[
u_i(t)=b_i+\sum_{j=1}^{N}w_{ij}x_j(t-\tau_{ij})+\alpha_i s_i(t)+\epsilon_i(t)
\]

\[
x_i(t+\Delta t)=(1-\gamma_i)x_i(t)+\gamma_i\,\sigma(u_i(t))
\]

with logistic nonlinearity

\[
\sigma(z)=\frac{1}{1+e^{-z}},\qquad 0<\gamma_i\leq1.
\]

Here (b_i) is bias, (	au_{ij}) is a modeled delay, (s_i(t)) is a normalized input, (alpha_i) is input gain, and (epsilon_i) is explicitly modeled noise. Parameters require calibration before interpretation. The formula is an optional model design, not a claim that the current TypeScript simulator implements this exact update.

## 4. Leaky integrate-and-fire (LIF) candidate

A common simplified neuron model is:

\[
\tau_m\frac{dV_i}{dt}=-(V_i-E_L)+R_m I_i(t)
\]

When (V_i\geq V_{\mathrm{th}}), emit a spike and reset (V_i\leftarrow V_{\mathrm{reset}}); optionally enforce a refractory interval. Here (V) is membrane potential, (E_L) resting potential, (	au_m) membrane time constant, (R_m) membrane resistance, and (I) input current. Units must be internally consistent.

For a discrete Euler step:

\[
V_i^{t+1}=V_i^t+\frac{\Delta t}{\tau_m}\left[-(V_i^t-E_L)+R_m I_i^t\right].
\]

The step size must be small enough for numerical stability and the model's intended time scale. LIF is an approximation; it omits detailed ion-channel dynamics.

## 5. Spike trains and rate estimates

Represent detected spikes for channel (i) as event times (\{t_{i,k}\}_{k=1}^{K_i}). For observation window length (T):

\[
\hat r_i=\frac{K_i}{T}\quad\text{spikes/second}.
\]

For a sliding window ([t-h,t]):

\[
\hat r_i(t)=\frac{\#\{t_{i,k}:t-h<t_{i,k}\leq t\}}{h}.
\]

A binned spike-count model may use (K_i\sim\operatorname{Poisson}(\lambda_i T)) as a baseline null model. Real neural activity can be bursty, refractory, nonstationary, and overdispersed; assess goodness of fit rather than assuming Poisson behavior.

## 6. Burst and synchrony definitions

A burst detector must be parameterized and recorded in experiment metadata. Example population activity in bin (k):

\[
P_k=\sum_{i=1}^{N}\mathbf{1}[K_{i,k}>0].
\]

Define a population-burst event when (P_k\geq\theta_P) for at least (m) consecutive bins, where (	heta_P) and (m) are declared before analysis. Report sensitivity to threshold choices.

A simple pairwise synchrony statistic is the Pearson correlation of binned spike counts:

\[
\rho_{ij}=\frac{\operatorname{Cov}(X_i,X_j)}{\sigma_{X_i}\sigma_{X_j}}.
\]

It measures co-variation, not direct causation or a synapse. Common input, volume conduction, shared artifacts, and bin size can produce apparent relationships.

## 7. Functional connectivity estimates

Possible analysis methods include cross-correlation, jitter-corrected correlation, generalized linear models, and mutual information. Every output must include method name, parameters, bin/window sizes, data source, and uncertainty or limitations.

For binned counts (X,Y), empirical mutual information is:

\[
I(X;Y)=\sum_{x,y}p(x,y)\log\frac{p(x,y)}{p(x)p(y)}.
\]

Use a consistent logarithm base (natural logarithm gives nats; base 2 gives bits). Finite-sample bias can inflate estimates. Use shuffle controls or bias correction and do not interpret mutual information as proof of a physical connection.

## 8. Plasticity hypothesis (optional simulation)

An illustrative spike-timing-dependent plasticity (STDP) update for a pair of pre/post spikes separated by (\Delta t=t_{post}-t_{pre}):

\[
\Delta w=
\begin{cases}
A_+e^{-\Delta t/\tau_+}, & \Delta t>0\\
-A_-e^{\Delta t/\tau_-}, & \Delta t<0
\end{cases}
\]

Apply bounded weights (w\leftarrow\operatorname{clip}(w+\Delta w,w_{min},w_{max})). This is a family of hypotheses, not a universal biological rule. The simulator must label it as synthetic plasticity unless independently validated against data.

## 9. Entropy and experiment performance

For categorical outcomes with probabilities (p_k), Shannon entropy is:

\[
H(X)=-\sum_k p_k\log_2 p_k.
\]

For a task, report entropy alongside accuracy, reward, latency, and baseline performance. A reduction in output entropy alone does not demonstrate learning; a constant or failed output can also have low entropy.

## 10. Units, assumptions, and reporting

- Store timestamps in a documented monotonic unit (prefer integer microseconds or nanoseconds at API boundaries).
- Distinguish samples, detected spikes, channels, model nodes, and biological cells.
- Store voltage units explicitly (for example, microvolts for extracellular samples).
- Store current, pulse width, sampling rate, and channel map only when sourced from the actual device/configuration.
- Do not copy simulator parameters into a physical-device protocol as validated biological settings.
- Attach source mode, software version, random seed, configuration hash, analysis version, and recording identifier to every result.
